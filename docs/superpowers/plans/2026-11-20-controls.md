# Ovládací prvky (HUD slidery, přepínače, obálka) – implementační plán

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Nahradit číselná pole, posuvníky a malé selecty dotykovými HUD ovladači a přidat obálku ADSR jako graf s tažením uzlů.

**Architecture:** Čistá logika bez DOM v `js/hud.js` (převody hodnota ↔ pruh, geometrie obálky, rozklad tónu dronu) s Node testy. `js/module.js` dostane omezení a slučování obálky. DOM komponenty v `js/controls.js` (slider, přepínač) a `js/envelope.js` (SVG graf). `ui.js` je jen osadí.

**Tech Stack:** Vanilla JS/CSS/SVG, pointer events, `node --test`.

**Spec:** `docs/superpowers/specs/2026-11-20-controls-design.md`

## Global Constraints

- Vanilla JS/CSS, žádné závislosti, cesty relativní; service worker `pulsar-v13`, nové soubory (`js/hud.js`, `js/controls.js`, `js/envelope.js`) do `FILES`.
- Slider = kreslený HUD pruh + průhledný nativní `<input type=range>` nad ním (hybrid). `createSlider({ min, max, step, value, scale, format, onInput, ariaLabel, nudge })` → `{ node, set(value) }`; `set` nevolá `onInput`. `nudge`: `false` nebo číslo kroku; tlačítka −/+ jen v detailu.
- Přepínač: `createSegmented({ options, value, onChange, ariaLabel })` → `{ node, set(value) }`, `radiogroup`, tlačítka aspoň 44 px.
- Rozsahy a kroky: `bpm` 20–300 (1), `swing` 0–1 (0,05), `randomize`, `rhythm mod`, `rate` 1–10 (1), `pan` −1–1 (0,05), hlasitost a úroveň sendu 0–1 (0,01; nudge 0,05), `octaves` 1–4 (1), `max extra` 0–6 (1), `fade` 0,5–30 (0,5), delay `time` 10–2000 (10), `feedback` 0–0,9 (0,05), `tone` 200–12000 (100), `return` a `damping` 0–1 (0,05), reverb `decay` 0,3–10 (0,1).
- Přepínače: `osc` (`WAVES`), `pitch` (`scale`/`notes`), `evolution` (`drift`/`walk`). Nativní `select` zůstává: `root`, `scale`, cíl sendu, tón dronu.
- Textová pole zůstávají jen pro `notes`, `rhythm`, `kick`, `snare`, `hat` a přejmenování (jméno není parametr zvuku).
- Obálka ADSR: uzly se táhnou i ovládají šipkami; `a`, `d`, `r` 0–5 s, `s` 0–1; `setParam('env', částečný objekt)` slučuje s aktuální obálkou modulu a omezuje; živé volání při každém pohybu; formát scény a zvuk se nemění.
- Drone `base`: tón (`ROOTS`) + oktáva 0–6 → `rootNote` `${root}${oktáva}`; enharmonické zápisy (`Db`, `D#`, `Gb`, `G#`, `A#`) se jen zobrazí jako `C#`, `Eb`, `F#`, `Ab`, `Bb`; modul tón mimo C0–C6 odmítne a ovladač se vrátí na přijatou hodnotu.
- Žádný ovladač nevolá `setParam` při prvním vykreslení ani při synchronizaci; zobrazená hodnota je vždy ta, kterou modul či efekt přijal.
- Dotyk: nativní range `touch-action: pan-y`; uzly obálky `touch-action: none`, plocha uzlu aspoň 44 px; všechny ovladače aspoň 44 px na výšku; 320 px bez vodorovného posouvání.
- Testy: `npm test`; UI se ověřuje v Chrome (po změně souborů smazat service worker, cache a vynutit znovunačtení souborů).

## Review Focus

- Slider dostane od modulu jinou hodnotu, než poslal (omezení, zaokrouhlení): zobrazí přijatou; `NaN`, `null`, text a hodnoty mimo rozsah z `set()` a `snap()` nevyhodí výjimku.
- Drone: `C0`, `C6`, `Db2` (uloženo ve scéně) a pokus o `B6`: uložená hodnota se při načtení ani prvním vykreslení nepřepíše; neplatný výběr se vrátí na platný.
- Obálka: tažení za hranice grafu (ukazatel mimo SVG), `a` = 0 a 5, `s` mimo 0–1, klávesy na hranách; zpětný převod z pozice dává platné hodnoty a krátký náběh 0,01 s jde vybrat.
- Dotyk a 320 px: svislé tažení na slideru roluje, na uzlu obálky ne; všechny ovladače v detailu každého typu modulu a efektu aspoň 44 px a bez přetékání.
- Rychlé události: jeden `onInput` na jednu změnu inputu, `set()` nevytvoří zpětnou smyčku, šipka na slideru (i s logaritmickým mapováním) posune přesně o jeden krok; nudge na hranách nepřeteče.

### Task 1: Čistá logika (`js/hud.js`)

**Files:**
- Create: `js/hud.js`
- Test: `tests/hud.test.js`

**Interfaces:**
- Produces (všechny čisté funkce):
  - `snap(value, { min, max, step }) → number`: omezí do `[min, max]`, zaokrouhlí na nejbližší násobek `step` od `min`, odstraní plovoucí šum (`0.1 + 0.2` → `0.3`); nečíselný vstup (`NaN`, `null`, `undefined`, text, `Infinity`) vrací `min`.
  - `toFraction(value, { min, max, scale = 'linear' }) → number` v `[0, 1]` (`'log'` je logaritmické mapování, jen pro `min > 0`).
  - `fromFraction(f, { min, max, step, scale = 'linear' }) → number`: inverzní k `toFraction`, výsledek přes `snap`.
  - `envLayout({ w, h, pad }) → layout`; `nodePositions(env, layout) → { attack, decay, release, start, sustainEnd }` (každé `{ x, y }`); `envFromDrag(node, point, env, layout) → částečná obálka`, kde `node` je `'attack' | 'decay' | 'release'` a výsledek obsahuje `{ a }`, `{ d, s }` nebo `{ r }`, vždy v mezích a zaokrouhlený na 0,01.
    - Graf má čtyři stejně široké úseky (náběh, pokles, pevný sustain, doznění); čas úseku se na jeho šířku mapuje odmocninově (`sqrt(t / 5)`), aby krátké hodnoty šly vybrat.
  - `splitRoot(rootNote) → { root, octave } | null` (`null` pro nerozpoznatelné), `joinRoot(root, octave) → string`.
- Consumes: `ROOTS` z `js/options.js`, `parseNote` z `js/scales.js`.

- [ ] **Step 1: Write the failing tests**

`tests/hud.test.js`, každý test jeden případ:
- `snap` omezí mimo rozsah (`snap(5, {min:0,max:1,step:0.05}) === 1`), zaokrouhlí na krok (`snap(0.37, {min:0,max:1,step:0.05}) === 0.35`), respektuje `min` jako počátek mřížky (`snap(2, {min:0.5,max:30,step:0.5})`), bez šumu (`snap(0.1+0.2, {min:0,max:1,step:0.1}) === 0.3`); `NaN`, `null`, `undefined`, `'abc'`, `Infinity` → `min`.
